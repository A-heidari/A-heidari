## Featured Projects

### 1. Credit Card Fraud Detection

A classification project focused on detecting fraudulent transactions in a highly imbalanced financial dataset.

- Dataset: 284,807 transactions, including 492 fraudulent transactions.
- Implemented Logistic Regression, Linear SVM, Polynomial SVM, and RBF SVM.
- Applied feature engineering, StandardScaler, Pipeline, and class-weight balancing.
- **Best F1-score: 0.7087** using Polynomial SVM.
- Explored Precision–Recall trade-offs and validation-based decision threshold selection.
- Investigated the impact of false positives and false negatives on model performance.

[View Repository](https://github.com/A-heidari/fraud-detection)

### 2. Customer Churn Prediction

A machine learning project focused on predicting customer churn using the Telco Customer Churn dataset.

- Performed data cleaning, exploratory data analysis, and feature engineering.
- Built preprocessing workflows using Pipeline, ColumnTransformer, imputation, and OneHotEncoder.
- Used stratified splitting and 5-fold GridSearchCV for Decision Tree model selection.
- **Test ROC-AUC: 0.7799**
- **Test F1-score: 0.5585**
- Compared classification performance using multiple evaluation metrics.

[View Repository](https://github.com/A-heidari/Customer-churn-prediction)

### 3. Used Car Price Prediction

A regression project focused on predicting used-car selling prices using the Cardekho dataset.

- Dataset: 15,411 vehicle records and 14 features.
- Performed exploratory data analysis and feature engineering.
- Applied target transformation using `log1p`.
- Built and compared regression models, including Linear Regression and Random Forest.
- Used RandomizedSearchCV for hyperparameter optimization.
- Evaluated models using MAE, RMSE, MAPE, and R².
- **Best Random Forest Validation R²: 0.8233**
- **Validation MAE: 110,943.67**
